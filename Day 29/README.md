Kickstarter Campaign Analysis (SQL Project)

Overview
This project explores Kickstarter campaign data to understand factors that influence project success and failure. The analysis was conducted using SQL and focused on campaign categories, funding performance, and backer engagement.

Objectives
• Identify which types of projects are more likely to succeed
• Analyze patterns among failed campaigns
• Measure how close unsuccessful projects came to meeting their funding goals

Skills Demonstrated
• Data querying using SQL
• Filtering and sorting large datasets
• Creating calculated performance metrics
• Applying conditional logic with CASE statements
• Translating data findings into business insights

Key Analysis Performed
• Selected relevant project features such as category, funding goal, pledged amount, and backers
• Filtered campaigns by outcome and funding size
• Calculated funding performance ratio (pledged vs goal)
• Categorized projects into Fully Funded, Nearly Funded, and Not Nearly Funded groups

Key Insight
Many failed projects still attracted considerable funding and backers but fell short due to ambitious funding targets. This suggests that goal-setting strategy plays a critical role in campaign success.

Conclusion
This project highlights how SQL can be used not just to retrieve data, but to explore patterns, test business assumptions, and uncover actionable insights.
